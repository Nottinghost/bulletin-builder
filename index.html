If a printer renders these differently than expected, nudge them here until a test print looks right.
Best browser for printing/saving: Use Chrome or Edge — both render this page's colors and layout correctly and reliably. Safari has known quirks with pages like this one (it can miss the page orientation, add an unexpected margin, or be slow enough that it looks frozen while it works out the colors) — if Safari is all you have, give it a bit before assuming it's stuck, and double-check the result.

Which button to use: both Download PDF buttons make a 3-page PDF, same format: each page is two identical portrait half-sheets side by side, printed double-sided and cut down the middle. Half-Sheet Bulletin is page 1 = service info, page 2 = people/attendance/nursery, page 3 = announcements. Prayer Bulletin is page 1 = missionary/shut-in/church family/today, page 2 = Prayer Focus, page 3 = Physical Concerns — split across pages the same way since those two lists tend to run long. Copy Link next to either one copies a link to a clean, phone-friendly page showing that bulletin instead — for texting or emailing, no file needed (and no cutting — that link is just for reading).

Always print from the downloaded PDF, not straight from this page: clicking a Download PDF button opens the browser's print window — set the destination to Save as PDF there (not a physical printer), save the file, then open that PDF (e.g. in Preview on a Mac) and print from it. Printing directly from this page can render fonts and spacing slightly differently depending on the browser; the saved PDF has been the one consistently correct result in testing, so treat it as the file to actually send to the printer.

To print either one from its PDF: use Letter paper with double-sided printing turned on — but since both documents are landscape, choose Short-Edge binding (sometimes labeled "Tumble" or "Flip on Short Edge"), not the usual Long-Edge/"Book" default. Long-edge duplex is correct for an upright portrait document; on a landscape one like these it flips the back side upside down. Each is always exactly 3 pages — if either one is ever cutting onto a 4th, something's overflowing and worth a look rather than just printing anyway.

To email or text it: click Copy Link next to the bulletin you want to share, then paste the link into the text or email — no file to attach, and it opens as a clean page on whatever they're reading it on. The link itself carries the bulletin's content, so it keeps working even after you've moved on to next week's — copy a fresh one each week.

If the PDF comes out in portrait, or with a bigger-than-expected white border: some browsers (Safari especially) don't switch to landscape on their own. In the print window, set Orientation to Landscape, Scale to 100%, and leave Margins on Default (not "None" — the page already carries its own safe margin, and forcing "None" can make a physical printer clip content it can't reach). Also turn on “Background graphics” (or “Print backgrounds”) if the navy and gold print white.

If a physical printout still looks clipped at the edge: double-check you're printing the saved PDF and not this page directly (see above). If it's still clipped, that's your printer's own hardware limit, not this file — every printer has a strip near the edge it physically cannot print into, and it varies by model. This tool's margin is set to clear that strip for the vast majority of printers. If you want truly edge-to-edge output, check the print dialog for a “Borderless” or “Full bleed” paper option — only your printer's own driver can turn that on.
